Solana-коммитмент + WORM

0 записей
Корень дерева подписывается Evidence Signer и фиксируется как коммитмент. Само видео и метаданные остаются в S3 Object Lock (WORM) — в сеть уходит только хеш.

Это офлайн-демонстрация логики протокола, а не подключение к реальной сети Solana: подписи и slot/timestamp сгенерированы локально для наглядности. Хеши SHA-256 — настоящие (Web Crypto API), структура Merkle-дерева и evidence package соответствуют пилотному гайду MD System.
